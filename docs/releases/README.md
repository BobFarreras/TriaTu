# Releases

Aquest directori guarda les notes de versio abans de publicar a produccio.

## Format recomanat

- Crea un fitxer per versio: `vX.Y.Z.md`
- Escriu un resum breu, canvis, riscos i passos de validacio.

## Exemple de plantilla

```
# v1.2.0

Data:
Resum:

## Canvis
- ...

## Riscos / Deute
- ...

## Validacio
- pnpm validate
```
