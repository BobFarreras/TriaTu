# Skills d'Agents

Aquest directori conté skills operatives per agents. Cada skill te un `SKILL.md` amb:
- objectiu i quan aplicar-la
- passos de treball
- referencies i assets

## Llistat de skills

- `triatu-architecture`: arquitectura i decisions estructurals
- `triatu-dev-workflow`: flux de treball de desenvolupament
- `triatu-features`: patrons i components per features
- `triatu-security`: seguretat i bones practiques
- `triatu-sentry`: observabilitat i Sentry
- `triatu-supabase`: base de dades i Supabase
- `triatu-testing`: testing i e2e
- `triatu-langsmith-prompts`: prompts i LangSmith

## Afegir una nova skill

1) Crea una carpeta nova a `docs/skills/<nom-skill>/`.
2) Afegeix un `SKILL.md` amb el format establert.
3) Actualitza aquesta llista.
